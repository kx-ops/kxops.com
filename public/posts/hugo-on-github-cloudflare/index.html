Hugo 静态站搭建于 GitHub,运行于 Cloudflare Workers

May 7, 2026

一、本站 kxops.com 运行架构#

环节所用服务
建站系统Hugo
编辑工具VS Code
网站托管GitHub
网站运行Cloudflare Workers

除域名外,全部 免费。由全球最具生产力的软件协作平台 GitHub 与全球最大的网络服务商 Cloudflare(人称"赛博活佛")提供加速动力。

费用提示 Cloudflare 开通 Workers 和 Pages 需要绑定银联卡,仅用于身份验证,不产生任何费用。免费版每日可承接 10 万次请求,详见 Cloudflare 开发者平台方案。

GitHub 只需要注册账号即可使用。

二、部署流程总览#

整个发布链路分三步:

  1. 本地生成 — 在本地电脑用 Hugo 构建静态文档
  2. 推送仓库 — 通过 git push 将 public/ 目录推送到 GitHub
  3. 自动部署 — Cloudflare 监听 github.com/kx-ops/kxops.com 的变动,自动更新网站
[本地 Hugo] ──git push──▶ [GitHub 仓库] ──webhook──▶ [Cloudflare Workers]

三、本地电脑安装 Hugo#

1. 下载安装包#

  • Hugo(Windows):hugo_0.161.1_windows-amd64.zip
  • Git(Windows):Git-2.54.0-64-bit.exe

2. 配置 Hugo 环境变量#

  1. 点击 Windows 开始菜单,输入 “环境变量”
  2. 选择 “编辑系统环境变量”
  3. 在弹出窗口中,点击右下角 “环境变量” 按钮
  4. 在"系统变量"栏中,找到 Path 变量并双击
  5. 在右侧点击 “新建”,粘贴 Hugo 所在目录,例如 D:\Hugo
  6. 依次点击 “确定” 保存全部窗口

3. 创建第一个站点#

打开命令提示符,依次执行:

cd /d D:\hugo\kxops.com
hugo new site kxops.com
cd kxops.com
hugo new posts/hello-world.md

最后一行会创建你的第一篇文章 hello-world.md。用 VS Code 打开 D:\hugo\kxops.com\posts\hello-world.md 即可开始编写。

四、GitHub 相关配置#

1. 生成 SSH 密钥#

在命令提示符中执行:

ssh-keygen -C "git@kxops.com"

一路回车即可,密钥会生成在:

C:\Users\你的用户名\.ssh\

2. 复制公钥内容#

cat ~/.ssh/id_ed25519.pub

复制输出的全部文本。

3. 将公钥添加到 GitHub#

  1. 登录 GitHub,点击右上角头像 → Settings
  2. 左侧菜单找到 SSH and GPG keys
  3. 点击右上角 New SSH key
  4. 填写信息:
    • Title:随意命名,例如 Win11-PC
    • Key:粘贴刚才复制的公钥内容
  5. 点击 Add SSH key 完成,即可实现 SSH 免密登录

4. 创建并初始化仓库#

先在 GitHub 创建仓库,例如 git@github.com:kx-ops/kxops.com.git(公开或私有均可)。

然后在本地初始化:

cd /d D:\hugo\kxops.com
echo "# kxops.com" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin git@github.com:kx-ops/kxops.com.git

5. 配置 .gitignore#

在 D:\hugo\kxops.com 目录下,用 VS Code 新建 .gitignore 文件,内容如下:

.vscode/
.idea/
.DS_Store
.run/
archetypes/
resources/
themes/
content/
.hugo_build.lock
hugo.toml

说明:此配置的作用是 只上传 Hugo 生成的静态页面目录到 GitHub,其他源文件全部忽略。

五、Cloudflare 部署设置#

  1. 登录 Cloudflare,在控制台选择 Workers 和 Pages → 创建应用程序
  2. 点击 Continue with GitHub
  3. 授权 GitHub 账号并选择对应仓库即可

部署完成后,Cloudflare 会自动监听仓库变动并发布到全球 CDN 节点。

六、日常更新流程#

1. 新建文章#

cd /d D:\hugo\kxops.com
hugo new posts/我的文章.md

2. 编写内容#

用 VS Code 或其他 Markdown 编辑器打开 D:\hugo\kxops.com\posts\我的文章.md,编辑后保存。

3. 构建并推送#

cd /d D:\hugo\kxops.com
rd /s /q public resources .hugo_build.lock
hugo --minify --gc --cleanDestinationDir --baseURL "https://kxops.com/"
git add .
git commit -m "更新"
git push origin main

推送完成后,Cloudflare 会自动重新部署,通常几十秒内即可在 kxops.com 看到更新。

至此,全文完。 🎉
