hugo 静态站搭建于Github 运行Cloudflare Workers

May 7, 2026

本站 kxops.com 运行方式#

  • 建站系统: Hugo
  • 网站存放: Github
  • 网站运行: Cloudflare Workers

使用vscode 作为markdown 编写器 除了域名外 全部免费 由全球最具生产力软件开发协作平台 Github.com 及 全球最大的网络服务商 Cloudflare.com (人称赛博活佛) 提供加速动力。

Cloudflare.com 开通Workers 和 Pages 需要绑银联卡 只需要验证 无费用产生 每日可有10万次点击 免费版详细说明 https://www.cloudflare.com/zh-cn/plans/developer-platform/

Github 只需要注册即可

安装部署流程如下

  1. 本地电脑安装 hugo 部署文档
  2. 产生的文档生成后 通过git push public变动推送到 github.com
  3. cloudflare监控 github.com/kx-ops/kxops.com 变动更新网站

本地电脑安装 hugo 及使用过程#

安装最新Windows版 hugo 下载地址 https://github.com/gohugoio/hugo/releases/download/v0.161.1/hugo_0.161.1_windows-amd64.zip

安装windows 版 git https://github.com/git-for-windows/git/releases/download/v2.54.0.windows.1/Git-2.54.0-64-bit.exe

打开环境变量设置 点击 Windows 开始菜单，直接输入 “环境变量”。 选择 “编辑系统环境变量”

在弹出的窗口中，点击右下角的 “环境变量” 按钮。 第三步：修改 Path 变量 在“系统变量” 栏中，找到名为 Path 的变量，双击它。 在弹出的窗口右侧点击 “新建”。 将你第一步复制的d:\Hugo 文件夹路径 粘贴进去。 依次点击 “确定” 保存所有窗口。

在命令提示输入

cd /d D:\hugo\kxops.com
hugo new site kxops.com
cd kxops.com
hugo new posts/hello-world.md ##这儿就可以创建第一个文档helloworld了

用vscode 打开 d:\hugo\kxops.com\posts\hello-world.md 编写即可

github 相应操作#

在Windows 下 生成自已的ssh-key 在命令提示符

ssh-keygen  -C "git@kxops.com"

按回车确认即可生成 你的密钥已生成在

C:\Users\你的用户名\.ssh\ 目录下

cat ~/.ssh/id_ed25519.pub 复制文本内容 将公钥添加到 GitHub 登录 GitHub，点击右上角头像 -> Settings。 在左侧菜单栏找到 SSH and GPG keys。 点击右上角的 New SSH key。 Title: 随便起个名字（例如 “Win11-PC”）。 Key: 将刚才复制的内容粘贴进去。 点击 Add SSH key，完成即可 实现ssh 登入

创建github 仓库 如git@github.com:kx-ops/kxops.com.git 设置公开或私有都可以

初始化hugo目录并使用 在命令提示符

cd /d D:\hugo\kxops.com
echo "# kxops.com" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin git@github.com:kx-ops/kxops.com.git

做完这些 我们用vscode 在d:\hugo\kxops.com 创建一个.gitignore 内容如下

vscode/
.idea/
.DS_Store
.run/
archetypes/
resources/
themes/
content/
.hugo_build.lock
hugo.toml

这个文件的意义 是我们只上传hugo生成的静态页面文件夹到 github.com 其它的文件都忽略

Cloudflare 部署设置#

登陆cloudflare 在 Cloudflare 控制台选择 Worker和 Pages -> 创建应用程序 点击 Continue with Github 。

授权 GitHub 账号并选择仓库即可。

每次更新的流程是

cd /d D:\hugo\kxops.com
hugo new posts/我的文章.md

然后使用vscode或者自已喜欢的markdown编辑器 编写D:\hugo\kxops.com\posts\我的文章.md 保存即可 更新到github 使用如下指令

cd /d D:\hugo\kxops.com
rd /s /q public resources .hugo_build.lock
hugo --minify --gc --cleanDestinationDir --baseURL "https://kxops.com/"
git add .
git commit -m "更新"
git push origin main

至此 全文完…
